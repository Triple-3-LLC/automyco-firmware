# Security policy

## Reporting a vulnerability

Please report security problems privately, through GitHub's private vulnerability reporting: open the **Security** tab of [Triple-3-LLC/automyco-firmware](https://github.com/Triple-3-LLC/automyco-firmware) and choose **Report a vulnerability**. Don't open a public issue for a security problem.

Tell us what you found, how to reproduce it, which version or commit you tested, and the hardware involved. We aim to acknowledge reports within 7 days.

## Scope

Anything in this repository, including anything that could let someone on the network, in Bluetooth range or on a web page drive a chamber's outputs (heater, atomizer, fans, UV-C lamp) or replace its firmware.

## Safety issues

If a bug can switch on the UV-C lamp or the heater unexpectedly, say so in the first line of the report. We treat those first.

## Supported versions

Only the latest release gets fixes.
